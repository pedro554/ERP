Projeto criado para ter um desafio de não utilizar a IDE do Delphi e ver o que acontece :);

Todos os componentes utilizados devem ser criados na mão e/ou estar na pasta componentes;

Qualquer alteração no banco de dados deve estar em database/migrations;

A pasta database/seed tem o banco de dados inicial, que não é muita coisa HASHSAHASH;

Padrão de projeto é o padrão que funciona desde que fique tudo bem separado e organizado;
